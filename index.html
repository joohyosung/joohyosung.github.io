05 / BACKEND · INFRASTRUCTURE

우리동네 안심지도

공공 생활안전 정보와 주민 관찰을 함께 살펴보는 지도 서비스입니다. 두 지역 비교·관리자 기능부터 DB 설계, 서버 구축과 배포까지 담당했습니다.

MY ROLE 두 지역 비교 · 관리자 기능 · DB 설계 · Node.js·Nginx 구축 · 배포·CI/CD

  • Node.js
  • Express
  • MySQL
  • Nginx
  • AWS EC2

문제 해결 과정 +
문제와 서비스
서로 다른 지역을 동일 반경과 축척으로 비교하고, 공공정보만으로 알기 어려운 현장 상황을 주민 안심노트로 함께 살펴보는 서비스를 만들었습니다.
직접 맡은 기능
A/B 두 지역 비교와 관리자 기능을 구현했습니다. 안심노트는 검토 상태에 따라 공개되며, 공개 목록과 상세에서는 승인된 노트만 제공하는 구조입니다.
DB 설계
사용자(users)와 안심노트(notes)의 1:N 관계를 설계했습니다. author_id 외래 키로 작성자를 연결하고 사용자 권한, 노트 상태와 관찰일 등의 데이터를 구성했습니다.
서버 구축과 배포
Node.js·Express 서버와 Nginx를 구축했습니다. AWS EC2 환경에서 GitHub Actions의 코드 검사·API 및 계산식 테스트·React 빌드와 SSH/SCP 전달을 연결한 CI/CD를 담당했습니다.
팀의 트러블슈팅
발표자료에는 WMS 요청을 1024px 묶음 타일로 줄이고 이미지를 재사용해 요청 수를 95건에서 4건으로, 첫 로딩을 4.97초에서 2.21초로 개선한 사례가 제시되어 있습니다.

지역 비교 점수는 가상 집계 기반 예시입니다. 실제 지역의 안전도를 나타내는 통계와 구분합니다.
